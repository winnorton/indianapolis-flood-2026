# WS4 — Uninsured Funding Path (users without flood insurance)

**Goal:** stack every non-insurance source. Most Marion County homes lacked flood coverage
(<1%), so this path is common — say that so the user doesn't feel foolish.

## The stack, in order

1. **FEMA (WS2 step 1)** is the anchor: housing repair/replacement help (capped, ~$43,600
   FY range), rental assistance outside the cap, and other-needs categories. FEMA is not a
   make-whole program; set expectations kindly.
2. **SBA loan (WS2 step 2)** is the largest tool: up to $500k at 3%/6% with a 12-month
   deferment. For many uninsured owners this is the realistic rebuild financing. FEMA may
   refer the user to SBA; completing that referral can also route them back for more FEMA
   other-needs help if declined.
3. **Indiana SDRF** grant (up to ~$5,000, uninsured essential losses, primary residence).
4. **Long-Term Recovery Groups / voluntary agencies** (local VOAD, faith-based rebuilds)
   handle unmet needs after the above — often labor and materials. The FEMA caseworker or
   211 can connect the user.
5. **Property-tax relief** (WS2 step 3).

## Important cautions

- **Duplication rules still apply:** each repair dollar has one payer; keep receipts by
  category (WS1 step 5).
- **Going forward, flood insurance may become mandatory:** if the user accepts federal
  disaster assistance for flood damage in the mapped floodplain, maintaining flood
  insurance is a condition of future aid (FEMA may provide an initial group policy).
  Budget for it.
- **Substantial damage rules (WS5) apply regardless of insurance.** An uninsured home can
  still be declared substantially damaged and required to elevate — without ICC money to
  help. The SBA mitigation increase and any future grant project become the funding path;
  route to WS7 for the decision.

## Stop / escalate

- If required elevation is unaffordable, ask DBNS and the city about any future
  acquisition/elevation programs and get on every interest list — but never stop the
  deadline items (WS2) while waiting.
