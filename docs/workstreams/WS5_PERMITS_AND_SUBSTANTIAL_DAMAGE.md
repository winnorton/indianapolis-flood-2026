# WS5 — Permits & Substantial Damage (significant damage, any tear-out, or any city letter)

**Goal:** the user goes through Indianapolis's process in the right order — permits before
work, determination understood before commitments — because this decision controls both
their obligations and (if insured) their $30,000 ICC benefit.

**Background for the agent (one paragraph):** Indianapolis DBNS decides whether repair cost
≥ 50% of the home's pre-flood *market* value. At/over 50% = "substantially damaged": the
home must be brought into compliance (lowest floor at Base Flood Elevation + 2 ft) and, if
insured, ICC can pay up to $30k toward that work. Under 50%: repair in place, no ICC. The
homeowner can influence the inputs honestly: an independent appraisal sets the value
(denominator); a careful repair estimate sets the cost (numerator).

## Steps

1. **Call DBNS now** — 317-327-7800 / PermitQuestions@indy.gov (script: spec Appendix B).
   Ask about: permit requirements, fee-waiver eligibility (window closed **2026-09-13** —
   if past, ask what fee relief remains), Substantial Damage Evaluation intake, and a
   **written site-specific flood determination** (BFE, floodway vs fringe, required design
   elevation). *Done when:* a dated written response or intake number exists.
2. **Pause non-emergency repair work** until DBNS states the permit path. Emergency
   protective work continues. If any letter mentioning substantial damage has arrived,
   this pause is mandatory — proceeding can cost tens of thousands.
3. **Commission an independent licensed appraisal** of pre-flood market value. Neutral
   instructions only — never steer the appraiser. *Done when:* signed appraisal received.
4. **When the determination letter arrives, check it the same day** for three elements:
   (a) substantially damaged yes/no with the percentage/basis, (b) that qualifying damage
   was **caused by flood** (ICC requires this), (c) the market-value basis used.
   Missing element → request a corrected letter in writing immediately.
5. **Floodway check before any design:** if the parcel might touch the regulatory floodway,
   an Indiana DNR review/permit comes FIRST and new residential construction in the
   floodway is prohibited. Get it in writing via the Indiana Floodplain Information Portal
   (FARA) — a GIS map is not a determination.
6. **Submit the complete permit package** DBNS specifies — only what they define as
   complete counts.

## Stop / escalate

- User disagrees with a determination (either direction) → reassessment/appeal paths exist
  (better appraisal + detailed estimate; Chapter 565 appeal). Deadlines run from the
  letter — calendar them first, then get professional help.
- Anyone suggests hiding damage or splitting permits to dodge the 50% rule → refuse;
  that's fraud with federal consequences.
