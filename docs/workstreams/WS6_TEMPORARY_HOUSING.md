# WS6 — Temporary Housing (displaced users — run FIRST)

**Goal:** the household is stably housed while everything else proceeds.

## Steps

1. **Tonight:** if there is no safe place to stay, direct to 211 (Indiana 2-1-1), local
   shelters, and family/friends. Safety first, paperwork second.
2. **FEMA displacement help (apply — WS2 step 1):** registration triggers review for
   upfront Displacement Assistance (flexible short-term lodging cash) and Lodging Expense
   Reimbursement — **keep every hotel receipt**.
3. **FEMA rental assistance:** initial ~2 months, renewable up to 18 months while the home
   is uninhabitable and the user shows a permanent housing plan. It sits OUTSIDE the FEMA
   housing cap — using it does not shrink repair money.
4. **IHCDA (state) choice:** hotel voucher up to 30 days **or** rental help (application
   fee + one month's rent + deposit) — mutually exclusive; rental help is usually worth
   more if the displacement will be long. State hub: in.gov/dhs → August 2026 disaster.
5. **Coordinate, don't duplicate:** the same week of lodging can't be paid by both FEMA
   and a state program or insurance loss-of-use. One payer per expense; receipts by
   category (WS1).

## Stop / escalate

- Household members with medical needs, disabilities, or school-age children needing
  stability → mention it in the FEMA application; accessibility-related help has extra
  room in the rules.
- Displacement stretching past a couple of months → recheck rental-assistance
  recertification dates so the 18-month runway doesn't lapse by paperwork.
