rather than a guess. Update after every settlement, award, or bid change.

## The 50% test

| Line | Amount | Source document |
|---|---|---|
| DBNS eligible repair cost | $__________ | |
| Accepted pre-flood market value | $__________ | |
| **Substantial-damage ratio** (repair ÷ value) | __________% | |

≥ 50% → substantially damaged: ICC eligible, elevation to BFE + 2 ft required.
< 50% → no ICC, no elevation mandate.
